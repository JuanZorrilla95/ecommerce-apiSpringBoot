*   DTO: Data Transfer Object.e sirve para mover datos entre distintas partes de un programa, como servidor y cliente,
*   conceptos fundamentales de spring:
* - @Entity: esta clase representa una tabla de la base de datos.
* - JpaRepository: Spring genera la implementación automáticamente.
* - Métodos derivados: findByEmail() funciona porque Spring interpreta el nombre del método y genera la consulta.

Uso de JpaRepository
