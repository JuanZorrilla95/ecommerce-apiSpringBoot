# E-Commerce API

REST API para un sistema de e-commerce desarrollada con Java y Spring Boot.

El proyecto está orientado a practicar y aplicar conceptos de desarrollo backend moderno, incluyendo:

- Arquitectura por capas
- APIs REST
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Validaciones
- Manejo de excepciones
- Autenticación mediante JWT
- Autorización basada en roles
- Docker
- Flyway
- Seguridad con Spring Security

---

## Tecnologías

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- PostgreSQL
- JWT
- Flyway
- Maven
- Docker / Docker Compose
- IntelliJ IDEA / VS Code
- DBeaver
